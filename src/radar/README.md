# src/radar

Radar BEV processing and RSU radar modules for the thesis.

Files copied from / adapted from V2Xverse (https://github.com/CollaborativePerception/V2Xverse):
- radar_bev.py, radar_runtime_stage9b.py, radar_online_packet_stage9b.py (from opencood/data_utils/radar/)
- rsu_radar_bev.py, rsu_radar_bev_warp.py (from simulation/leaderboard/team_code/)
- reference/rsu_radar_oracle.py: oracle version for debugging only, not part of the deployable method

These modules expect a working V2Xverse installation (see environment/).
